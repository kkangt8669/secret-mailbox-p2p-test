① 시험방 준비
수동 교환은 SDP 텍스트를 두 기기 사이에서 복사·전달해야 함. Firebase 자동 교환은 별도 인증·보안 규칙이 구성된 시험 DB에서만 사용 권장.
대기연결 안 됨
② 수동 연결 정보 교환
방을 설정한 후 연결 시작을 누르십시오.
A는 자신의 offer를 B에게 보내고, B는 붙여넣어 answer를 생성한 후 A에게 되돌려 보내면 됨. 직접 전달한 SDP에는 네트워크 IP 정보가 포함될 수 있으므로 공개 게시 금지.
② Firebase 자동 연결 협상
경로: /rooms/{방번호}/p2p_mobile_v12/ · SDP 내용은 공유 암호로 AES-GCM 암호화한 뒤 3분 기한으로 기록함. 접근 권한 거부 시 Firebase 규칙을 전체 공개하지 말 것.
③ P2P 메시지 시험
연결 성공 후 메시지 입력 가능
메시지는 AES-GCM으로 암호화되어 DataChannel로만 전송. 상대방 미접속 시 암호문은 이 브라우저의 로컬 저장소에 전송 대기 상태로 남음. 브라우저 데이터 삭제 시 대기 메시지 손실 가능.
